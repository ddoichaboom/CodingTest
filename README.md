# CodingTest

C++로 푼 코딩 테스트 문제와 공부 기록을 모아두는 저장소입니다.

## 학습 방식

섹션 단위로 **개념 학습 → C++ 복습 → 문제 풀이 → 회고** 순서로 진행합니다.

문제 하나는 다음 순서로 풀고, 기록은 다 푼 뒤가 아니라 푸는 중에 남깁니다.

1. **읽기·분석** — 문제를 내 말로 요약하고, 제약 조건에서 허용되는 시간복잡도를 계산
2. **설계** — 코드를 쓰기 전에 후보 방법들의 복잡도를 비교해 선택
3. **테스트 먼저** — 입출력 예와 직접 떠올린 엣지 케이스를 `test.cpp`에 작성
4. **구현** — `solution.cpp`를 작성하고 로컬 테스트 통과
5. **제출** — 실패하면 원인을 분석하고, 놓친 케이스를 테스트에 추가
6. **리뷰** — 대안 풀이와 비교하고, C++ 관점의 개선점 정리
7. **정리** — 풀이 기록(README) 마무리 후 커밋

## 구조

```
Programmers/
├── Algorithm/                 # 코딩테스트 고득점 Kit
│   └── 01_Hash/
│       ├── README.md          # 섹션 개념 + 문제 목록 + 회고
│       └── 01_<문제명>/
│           ├── README.md      # 풀이 기록 (문제 원문 포함)
│           ├── solution.cpp   # 제출 코드
│           └── test.cpp       # 로컬 테스트
└── CodingTest/                # 코딩테스트 연습 문제
Study/                         # 공부 기록 (C++ 등)
tools/                         # 문제 폴더 생성 · 테스트 도구
```

## 도구

필요: g++ (C++17), Python 3

```
python tools/new.py <문제 번호> <섹션 폴더>    # 문제 폴더 생성 (원문 · 시작 코드 · 입출력 예)
python tools/test.py [문제 폴더]               # 컴파일 + 테스트 실행 (생략 시 전체)
```
