# CodingTest

코딩 테스트 문제 풀이와 공부 기록을 모아두는 저장소입니다.

## 구조

```
Programmers/        # 프로그래머스 문제 풀이
├── Algorithm/      # 알고리즘 문제
└── CodingTest/     # 코딩 테스트 문제
Study/              # 공부 기록 (카테고리별 하위 폴더)
```

이전 구성(날짜별 폴더, 프로그래머스 코딩테스트 입문 풀이)은 [이전 커밋](https://github.com/ddoichaboom/CodingTest/tree/1c07b059d6ce7eb53b512bc69147997700b7083a)에서 볼 수 있습니다.
